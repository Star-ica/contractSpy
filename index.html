Security Features
Complete Threat Intelligence Suite
Everything you need to keep your contracts secure — from real-time monitoring to on-chain alert storage.
👁️
Real-Time Monitoring
Continuously query BOT Chain RPC to detect ownership changes, minting events, and admin operations the moment they happen.
🚨
On-Chain Alert Records
Every confirmed threat is stored immutably on BOT Chain, creating a tamper-proof audit trail of all security events.
🔍
Transfer Analysis
Detect unusual token movements and large withdrawal patterns that could indicate exploits or rug-pull preparation.
⚙️
Upgrade Detection
Monitor proxy contract upgrades and administrative changes in upgradeable contracts for unauthorised modifications.
📊
Security Reports
Submit, discover and upvote community security reports — all stored on-chain for community-driven threat intelligence.
🔧
Custom Rules
Configure per-contract monitoring rules with custom thresholds for transfer amounts and activity volume.
Process
How ContractWatch Works
A transparent, decentralised security workflow with no centralised backend.
1
Connect Wallet
Connect your MetaMask or compatible wallet. ContractWatch registers your profile on BOT Chain.
2
Register Contract
Add any smart contract address. Your monitoring configuration is stored on-chain.
3
Monitor Events
While the app is open, it polls BOT Chain RPC for events matching your security rules.
4
Record On-Chain
Review each detection and record confirmed threats as immutable on-chain alerts. Acknowledge them once resolved.
